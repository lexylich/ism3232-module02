# ISM3232 - Module 2: zsh Navigation and File Operations

## Commands Practiced

| Command        | What it does                            |
|----------------|------------------------------------------|
| pwd            | Prints the current working directory    |
| ls             | Lists visible files and folders         |
| ls -la         | Lists all files including hidden ones   |
| cd             | Changes directory                       |
| touch          | Creates an empty file                   |
| echo           | Writes text to a file with >            |
| cat            | Prints a file's full contents           |
| head           | Prints the first N lines of a file      |
| cp             | Copies a file, original stays           |
| mv             | Moves or renames a file                 |
| rm             | Permanently deletes a file              |
| tree           | Visualizes folder structure             |
| code .         | Opens the current folder in VS Code     |
