lexy 2.0 is (will be) a personalized restaurant assistant that tells customers what menu items cost and when the restaurant open. It is a mock because it doesn't use any AI. It just looks for keywords in what the customer types, and the menu is a short list that I typed into the code. If someone asks about a reservation, a complaint, a refund, or an allergy, it says that it will hand them off to the manager, since those need a real person to make the call. If this used real customer data, the chat history could end up holding names, phone numbers, or allergy details, and that information would have to be kept private.
